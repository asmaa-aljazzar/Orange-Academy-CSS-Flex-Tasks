## 🌐 View the Exercises

This repository contains 12 exercise folders, from `ex01` to `ex12`.

To view a specific exercise using GitHub Pages, add the folder name to the end of this URL:

```text
https://asmaa-aljazzar.github.io/Orange-Academy-CSS-Flex-Tasks/
```

For example, to view exercise `ex01`:

```text
https://asmaa-aljazzar.github.io/Orange-Academy-CSS-Flex-Tasks/ex01/
```

To view exercise `ex05`:

```text
https://asmaa-aljazzar.github.io/Orange-Academy-CSS-Flex-Tasks/ex05/
```

Simply replace the number at the end of the URL with the exercise folder you want to view (`ex01`–`ex12`).
